Project summary:
I built a fraud classification and risk-scoring pipeline for a highly imbalanced dataset.
I compared Logistic Regression and Random Forest using precision, recall, F1-score, and average precision, then tested different thresholds to measure false positives, missed fraud, and manual-review workload.
For the selected high-risk transactions, I used SHAP to identify the strongest positive local feature contributions to each fraud score.
I then sent only verified model evidence to an LLM to create short analyst-facing notes.
Finally, I ran simple rule-based checks for missing evidence and unsupported real-world claims.
